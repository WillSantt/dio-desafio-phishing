# Projeto de Phishing - DIO Cybersecurity

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio educacional da Digital Innovation One (DIO), com o objetivo de compreender o funcionamento de ataques de phishing e analisar técnicas utilizadas na engenharia social.

O laboratório utiliza o Kali Linux e o Social-Engineer Toolkit (SEToolkit) para demonstrar, em ambiente controlado, como páginas fraudulentas podem ser utilizadas para simular tentativas de obtenção de credenciais.

## 🎯 Objetivos

- Compreender o funcionamento do phishing.
- Conhecer a ferramenta Social-Engineer Toolkit (SEToolkit).
- Explorar técnicas de engenharia social.
- Identificar riscos relacionados ao roubo de credenciais.
- Desenvolver conhecimentos práticos em cibersegurança.
- Documentar os procedimentos realizados no laboratório.

## 🛠️ Ferramentas Utilizadas

- Kali Linux
- Social-Engineer Toolkit (SEToolkit)
- VirtualBox

## 🧪 Ambiente de Laboratório

Os testes foram realizados em ambiente virtualizado e controlado, exclusivamente para fins educacionais.

## 📚 Aprendizados

Durante a execução do projeto, foram explorados conceitos relacionados a:

- Phishing e engenharia social.
- Segurança de credenciais.
- Identificação de páginas fraudulentas.
- Uso de ferramentas de segurança ofensiva.
- Importância da conscientização em segurança da informação.

## ⚠️ Aviso Legal

Este projeto possui finalidade exclusivamente educacional e de conscientização em segurança da informação.

Nenhuma credencial real deve ser coletada ou utilizada. Os testes devem ocorrer somente em ambientes autorizados e controlados.
